# Bean & Bloom

## Project Overview

Bean & Bloom is a clean and responsive café landing page created as part of the Web Development Week 1 assignment. The website presents a modern café experience with a simple and attractive layout.

## Objective

To create a responsive café landing page using HTML, CSS, and JavaScript while practicing webpage structure, styling, navigation, responsive design, and user-friendly layouts.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Responsive café landing page
- Clean and modern user interface
- Hero section with café branding
- Navigation menu
- Café services/content sections
- Contact section/form
- Mobile-friendly layout
- Responsive navigation
- Smooth and user-friendly page design
